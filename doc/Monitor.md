# Monitor 使用说明

默认访问：`http://localhost:8080/monitor/`（路径可由 `securtkit.monitor.path` 配置）。

Monitor 是**运维台**：核对运行时配置、做明密文对照、单行验签、历史刷数。与 [`Playground`](Playground)（业务演示）职责分离。

## 启用与登录

```yaml
securtkit:
  monitor:
    enabled: true
    path: /monitor
    username: admin
    password: admin   # 生产请更换，并限制网络访问
```

- `enabled=true` 时挂载 Servlet；未登录（若启用认证）无法调用 `/monitor/api/*`。
- 建议仅内网或经反向代理访问；勿把默认口令暴露到公网。

## 信息架构

登录后（或关闭认证后）默认进入 **工作台**。顶部 Tab：

| Tab | 作用 |
|-----|------|
| 工作台 | 环境摘要 + 跳转快捷入口 |
| 加密解密 | 单值加密 / 解密 / 签名 / 验签 |
| 验签 | 按表 + 主键读行、算摘要、比对 |
| 刷数作业 | 历史数据批量加解密 / 摘要回填（先预览再回写） |
| SQL | 查询双视图 / SQL 解析 / 参数加密 |
| 项目文档 | 页内精简接入指南（离线） |
| 配置信息 | 运行时生效的 mode、策略、表字段与 Digest |

每个功能页标题旁有 **使用说明**（眼睛按钮）：打开共用帮助弹窗，不挤占操作区高度。

---

## 工作台

- 汇总：加密模式（`JDBC` / `MYBATIS` / `OFF`）、是否启用、表/摘要数量、数据源数量、`verify-on-read`、`skip-comment` 等。
- 快捷入口：跳到 SQL 双视图、刷数、配置等信息页。
- **只看摘要**；完整规则请到「配置信息」核对。

---

## 加密解密（单值）

用于快速验证策略实现是否可用：

1. 输入明文 / 密文 / 待签名文本  
2. 选择数据源  
3. 执行加密、解密、生成签名或验签  

注意：这里调用的是策略本身，**不代表**某张表已正确配置该字段。

---

## 单行验签

按表名与主键读取一行，展示参与摘要的字段，并可生成摘要或与库中摘要比对。

1. 填写已配置 `digest` 规则的表名与记录 id（主键列可按配置留空或指定）  
2. 先「查询」，再「生成摘要」或「验签」  

### JDBC / MYBATIS

- 业务写入摘要仍按配置通道执行。  
- Monitor 验签在 **结果侧** 对加密源字段显式解密后再算摘要比对，**不依赖**把应用改回 JDBC 拦截。  
- `mode=MYBATIS` 下验签与 SQL 双视图仍可用。

验签失败常见原因：行被篡改、HMAC 密钥不一致、源字段拼接规则与写入时不同。

---

## 刷数作业

对历史数据批量加密、解密或摘要回填。

**强制流程：** 选表 → **预览**（最多约 10 行样例）→ 核对 → **确认回写**。

- 仅列出已配置规则的表。  
- 回写会改库：务必备份、低峰执行，不要跳过预览。  
- 旧「数据初始化」能力已并入本 Tab。

---

## SQL 工作区

同一 Tab 内分主视图：

### 查询（默认）

- **仅允许 SELECT**（禁多语句与写操作）。  
- 返回 **密文栏**（库内原值，旁路读）与 **明文栏**（按配置字段解密）。  
- **JDBC 与 MYBATIS 均可**：明文栏由 Monitor 显式解密，不要求 JDBC 拦截生效。  
- 函数投影（如 `IFNULL(phone,'2')`、`CASE` 等）按源加密字段解密**返回值**；会改写密文形态的函数可能解密失败并保留原值。

### SQL 解析

- 展示占位符 `?` 与加密字段映射。  
- 字面量 SQL **没有**占位符映射是正常的；已配置字段仍应出现在加密字段结果中。

### 参数加密

- 将 SQL 字面量中的敏感值替换为密文形态，**只生成 SQL，不执行** INSERT/UPDATE。

各子模式草稿相互独立，可切换保留输入。

---

## 配置信息

核对启动后生效的配置快照：

1. `enable` 与 `mode`  
2. 摘要策略与读取验签开关  
3. SQL 解析缓存  
4. 逐表字段策略与 digest 规则  

修改 `application.yml` 后通常需**重启**应用。

---

## 项目文档 Tab

Monitor 内嵌精简接入说明（依赖、通道、字段、Digest/LIKE、多数据源、FAQ），离线可用。更完整的手册见本 Wiki 其它页面与仓库 `doc/`。

---

## 安全建议

- 生产启用认证并更换默认口令  
- 限制 `/monitor` 网络暴露面  
- 刷数与 SQL 查询均可能接触敏感明文展示，按合规要求控制权限与审计  

## 相关配置片段

```yaml
securtkit:
  encryptor:
    enable: true
    mode: JDBC   # 或 MYBATIS
    skip-comment:
      enable: true
      token: SECURT_SKIP
  monitor:
    enabled: true
    path: /monitor
    username: admin
    password: ${MONITOR_PASSWORD}
```
