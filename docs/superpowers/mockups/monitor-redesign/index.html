Monitor 重设计 · 三种方案

打开下方任一方案查看线框。均为静态 HTML，用来对比信息架构与页面气质； 选定后再写正式设计文档与实现计划。

推荐 方案 1

侧栏分区运维台

工作台首页 + 左侧分区导航。排查 / 刷数 / 工具 / 配置分层，适合反复进出的运维场景。

 方案 2

顶部场景向导

三大场景（查问题 / 改数据 / 看配置）驱动分步流程，新手路径短，高手切换成本偏高。

 方案 3

多 Tab 视觉翻新

保留 Tab 结构，合并 SQL、加工作台首屏，改动最小，信息架构收益有限。
