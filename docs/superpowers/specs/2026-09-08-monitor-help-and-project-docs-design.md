# Monitor 页内帮助与项目文档设计

## 状态

已实现。

## 目标

在不增加各功能页长期占用空间的前提下，为 Monitor 每个主功能提供就近使用说明；同时新增独立的项目文档入口，让首次接入 Securt-Kit 的使用者能在 Monitor 内完成基础了解、集成和配置。

## 信息架构

顶部主导航保留现有功能，并新增「项目文档」Tab。

现有六个 Monitor 主功能页分别提供页内帮助入口：

1. 工作台
2. 加密解密
3. 验签
4. 刷数作业
5. SQL
6. 配置信息

## Monitor 页内帮助

### 入口

- 每个主功能页内容标题区右上角放置眼睛图标按钮。
- 按钮具有可见提示和 `aria-label`，不能只依赖图标表达含义。
- 点击按钮打开共用帮助弹窗，不改变功能区高度，也不触发页面重新布局。

### 内容

每个功能使用独立帮助内容，统一包含：

- 功能用途
- 操作步骤
- 关键字段或结果解释
- 风险提示与限制
- 最小可运行示例

SQL 帮助额外区分「查询」「SQL 解析」「参数加密」，并明确：

- 查询只执行 SELECT。
- SQL 解析用于查看占位符映射和配置的加密字段。
- 字面量 SQL 没有占位符映射是正常情况，但仍应识别配置的加密字段。
- 参数加密只生成转换后的 SQL，不直接执行修改。

### 弹窗行为

- 全站只使用一个帮助弹窗，根据入口的 `data-help-topic` 渲染对应内容。
- 支持关闭按钮、点击遮罩关闭和 Escape 关闭。
- 打开后焦点进入弹窗，关闭后焦点回到触发按钮。
- 弹窗正文限制最大高度并内部滚动。

## 项目文档 Tab

项目文档提供面向使用者的精简指南，不复制仓库全部设计文档。内容包括：

1. 项目简介与透明加解密流程
2. Spring Boot 2 与 Spring Boot 3 Maven 依赖
3. JDBC 与 MyBatis 两种通道的选择和配置
4. 加密表、字段及自定义策略配置
5. Digest、LIKE 和多数据源能力概览
6. Monitor 与 Playground 的用途和访问方式
7. 常见问题

项目文档采用左侧目录、右侧正文布局；窄屏下目录改为横向滚动导航。正文区域内部滚动，避免整页持续增长。

代码示例使用只读代码块，并提供复制按钮。复制成功或失败沿用 Monitor 现有通知机制。

## 数据与实现边界

- 文档内容随 Monitor 静态资源发布，不新增后端 API。
- 页内帮助和项目文档不读取外部站点，离线环境可用。
- 复用现有主 Tab 切换、通知和按钮风格。
- 不修改加密、验签、刷数及 SQL 接口。
- 本次只提供基础使用文档，不实现全文搜索、文档版本切换或在线编辑。

## 测试与验收

1. 六个 Monitor 主功能页均有可访问的帮助按钮。
2. 每个帮助按钮展示与当前功能匹配的内容。
3. 弹窗可通过关闭按钮、遮罩和 Escape 关闭。
4. 顶部导航包含独立「项目文档」Tab。
5. 项目文档覆盖依赖、通道、字段配置、Digest、LIKE、多数据源和常见问题。
6. 代码示例复制可用并给出反馈。
7. 帮助弹窗和项目文档在桌面与窄屏布局下无横向溢出。
8. 现有 Monitor 功能与 SQL 工作区回归测试继续通过。
