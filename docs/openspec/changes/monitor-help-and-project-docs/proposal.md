## Why

Monitor 已覆盖日常排查和运维操作，但各页面缺少就近说明，新使用者还需要离开控制台翻阅多个仓库文档才能理解项目接入、通道选择和配置方式。需要在不挤占现有操作空间的前提下补齐页内帮助，并提供一个可离线访问的项目文档入口。

## What Changes

- 为工作台、加密解密、验签、刷数作业、SQL 和配置信息六个 Monitor 主功能页增加可访问的帮助入口。
- 新增共用帮助弹窗，按当前功能展示用途、步骤、字段解释、限制和最小示例，并支持关闭按钮、遮罩和 Escape 关闭。
- 在顶部主导航新增「项目文档」Tab，提供项目简介、Boot 2/3 接入、JDBC/MyBatis 通道、字段策略、Digest、LIKE、多数据源、Monitor/Playground 和常见问题。
- 为项目文档代码示例提供复制操作和结果反馈。
- 保持帮助弹窗和项目文档内容区内部滚动，并适配窄屏布局。
- 文档随 Monitor 静态资源发布，不新增或修改后端 API。

## Capabilities

### New Capabilities

- `monitor-documentation-ui`: Monitor 六个功能页的上下文帮助、共用帮助弹窗及独立项目文档页面的内容与交互契约。

### Modified Capabilities

- （无）主规格目录尚无已归档的 Monitor 文档能力；本变更以新能力描述用户可见行为，不修改现有 API 能力要求。

## Impact

- **模块**：主要影响 `securt-kit-monitor` 的 `index.html`、`css/style.css` 和 `js/app.js` 静态资源。
- **导航**：现有顶部 Tab 增加「项目文档」，现有功能入口和默认工作台保持不变。
- **接口**：不新增后端 API，不修改认证、加密、验签、刷数、SQL 或配置接口契约。
- **依赖**：不增加第三方前端依赖；帮助和文档在离线环境可用。
- **测试**：增加静态资源结构、帮助弹窗交互、文档导航与复制功能测试，并回归现有 Monitor 测试。
