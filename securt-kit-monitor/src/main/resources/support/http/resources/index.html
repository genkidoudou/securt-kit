                                01 · Overview
                                
项目简介

                                
Securt-Kit 是数据库字段级透明加解密框架。应用仍读写明文，框架在 JDBC 或 MyBatis 通道拦截 SQL 参数与结果集，对配置字段自动加密入库、解密返回。

                                

                                    业务明文→SQL 拦截→密文入库→查询解密
                                

                                
适用于手机号、证件号、银行卡等敏感字段。Boot 2.7 支持 Java 8+，Boot 3 支持 Java 17+。

                            


                            

                                02 · Install
                                
添加依赖

                                
根据 Spring Boot 大版本选择对应 Starter，版本号请替换为项目实际发布版本。

                                
Spring Boot 2.7

                                

                                    
                                    
<dependency>
  <groupId>io.github.genkidoudou</groupId>
  <artifactId>securt-kit-starter-boot2</artifactId>
  <version>1.0-SNAPSHOT</version>
</dependency>

                                

                                
Spring Boot 3.x

                                

                                    
                                    
<dependency>
  <groupId>io.github.genkidoudou</groupId>
  <artifactId>securt-kit-starter-boot3</artifactId>
  <version>1.0-SNAPSHOT</version>
</dependency>

                                

                            


                            

                                03 · Mode
                                
选择加密通道

                                
JDBC 适合通用数据库访问；MYBATIS 适合 MyBatis / MyBatis-Plus 项目且无需修改驱动。同一数据源只能启用一种通道。

                                
JDBC 模式

                                

                                    
                                    
spring:
  datasource:
    driver-class-name: io.github.genkidoudou.core.interceptor.SimpleInterceptorDriver
    url: jdbc:interceptor:mysql://localhost:3306/app
securtkit:
  encryptor:
    enable: true
    mode: JDBC

                                

                                
MyBatis 模式

                                

                                    
                                    
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/app
securtkit:
  encryptor:
    enable: true
    mode: MYBATIS

                                

                            


                            

                                04 · Fields
                                
配置字段与策略

                                
按表和字段声明需要保护的数据。未指定策略时使用容器中的默认 FieldEncryptorStrategy；也可填写自定义实现类全限定名。

                                

                                    
                                    
securtkit:
  encryptor:
    enable: true
    failure-policy: FALLBACK
    tables:
      - table-name: user
        fields:
          - field-name: name
          - field-name: phone
            strategy: com.example.PhoneEncryptorStrategy

                                

                                
策略实现需提供可逆的 encryption 与 decryption，并正确处理 null。

                            


                            

                                05 · Integrity & Search
                                
Digest 与 LIKE

                                
Digest 用于字段完整性校验：根据一个或多个源字段生成摘要到目标字段，可开启读取验签。LIKE 默认采用精确匹配处理，可通过 LikePatternHandler 扩展自定义模式。

                                

                                    
                                    
securtkit:
  encryptor:
    digest-strategy: io.github.genkidoudou.core.strategy.HmacSha256DigestStrategy
    digest-hmac-key: ${DIGEST_HMAC_KEY}
    digest-verify-on-read: true
    tables:
      - table-name: user
        digest:
          - source-fields: [phone]
            target-field: row_digest

                                

                            


                            

                                06 · Datasource
                                
多数据源

                                
同名表在不同数据源可配置不同字段或策略。为表规则设置 datasource-id，其值应与应用的数据源标识保持一致。

                                

                                    
                                    
securtkit:
  encryptor:
    tables:
      - table-name: user
        datasource-id: primary
        fields:
          - field-name: phone
      - table-name: user
        datasource-id: archive
        fields:
          - field-name: id_card

                                

                            


                            

                                07 · Tools
                                
Monitor 与 Playground

                                
Monitor 位于 /monitor/，面向配置核对、SQL 对照、验签与刷数运维。Playground 位于 /playground/，面向开发阶段 CRUD、摘要和复杂 SQL 的交互演示。

                                
    
                                    
  • 生产环境使用 Monitor 前应配置认证，并限制网络访问范围。
    • 
                                    
  • 刷数作业必须先预览，再确认回写。
    • 
                                    
  • SQL 参数加密只生成 SQL，不会直接执行 UPDATE 或 INSERT。
    • 
                                

                            


                            

                                08 · FAQ
                                
常见问题

                                

                                    为什么数据库里还是明文？
                                    
先在配置信息页确认 enable、mode、数据源和表字段规则；JDBC 模式还需确认驱动和 URL 使用拦截前缀。

                                

                                

                                    为什么 SQL 解析没有占位符映射？
                                    
只有 ? 参数会产生占位符映射。字面量 SQL 没有映射是正常的，但已配置的 SET 字段仍会出现在加密字段结果中。

                                

                                

                                    JDBC 与 MyBatis 可以同时开启吗？
                                    
同一数据源不可以，否则同一参数可能被重复处理。请选择一个 mode。

                                

                                

                                    哪里查看更完整的说明？
                                    
仓库中的 README、docs/QUICK-START.md、docs/USAGE.md 和 docs/MULTI-DATASOURCE.md 提供完整细节。
